# 任务管理 App

一个适合 Android Studio 学习和继续扩展的 Kotlin + Jetpack Compose 本地应用。

## 当前功能

- 任务新增、完成、删除，记录截止时间和优先级
- 根据任务类型生成可编辑的小任务拆分建议
- 本机保存的备忘录
- 可选择 15、25、45、60 分钟或自定义专注时长，支持开始、暂停和重置
- 专注奖励：按时长解锁不同宠物食物，可喂食宠物
- 连续专注天数、累计专注时长
- 按任务类型和预计时长生成可编辑的行动计划

数据保存在应用本机的 SharedPreferences 中，无需注册账号或配置服务器。

## 当前实现边界

任务、笔记和成长记录保存在本机。任务拆分使用本地规则模板，不调用 AI 服务。当前版本不包含联网房间或跨设备同步，因此无需配置 Firebase；`app/google-services.json` 若已下载，只是未使用的配置文件，可手动删除。番茄钟结束通知尚未实现。
